# Research IdeaGen

Agentic framework for automated research ideation from scientific literature.

## Project Overview

This project develops agentic systems that can generate novel research ideas and plans by analyzing large corpora of academic literature. The system identifies gaps in existing literature, generates feasible research ideas, and evaluates their novelty, feasibility, and impact.

## Core Goals

- Build frameworks that ingest and analyze conference papers and scientific literature at scale
- Generate novel, feasible research ideas based on gaps, trends, and connections in the literature
- Develop methods for LLMs to evaluate and rank research ideas
- Create structured research plans from generated ideas

## Key Research Questions

- How can LLMs identify meaningful gaps in existing literature?
- What makes a research idea "good" and how can we operationalize this?
- How do we evaluate novelty, feasibility, and impact of generated ideas?
- Can LLMs learn to select better ideas through feedback or self-critique?
- How do we ground generated ideas in actual literature citations?

## Project Status
